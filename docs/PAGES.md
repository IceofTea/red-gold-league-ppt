# 页面类型手册

所有页面都是 `PAGES` 列表里的一个字典，靠 `t` 字段选择版式。`build()` 会先校验字段，再逐页渲染。

```python
PAGES = [
    {"t": "cover", ...},
    {"t": "chapter", ...},
    ...
]
```

通用规则：

- `script` 每页必填，150—250 字，会写进 Word 讲稿；
- 元组字段（`cards`、`items`、`events`、`numbers`、`points`、`deeds`）用 Python 元组；
- 图片字段可写绝对路径，也可写相对当前工作目录的路径；不确定时用 `Path(...).resolve()`；
- 文字里的 `\n` 是手动换行，只在确实需要断行时使用。

---

## `cover` 封面

```python
{
    "t": "cover",
    "kicker": "★ 主题团课",          # 顶部小字
    "years": "2026  ·  10",          # 年份/期数
    "title": "把青春写在祖国大地上",   # 主标题，建议 ≤ 16 字
    "subtitle": "从回望来路，到接力出发",
    "lead": "第一行导语\n第二行导语",  # 2—3 行
    "big": "31",                     # 右下角大数字，通常是页数
    "script": "……",
}
```

主标题超过 18 字会自动缩字号；仍建议控制在 16 字以内。

---

## `quote` 序章 / 金句 / 小结

```python
{
    "t": "quote",
    "chapter": "序章  ·  为什么出发",  # 页眉
    "small": "一次关于选择与担当的讨论",
    "big": "青春，应该在哪里闪光",     # 金句，建议 ≤ 20 字
    "sub": "答案不在口号里，而在每一次真实的选择里。",
    "note": "—— 示例主题团课",        # 可选
    "script": "……",
}
```

适合放在序章、每章结尾或全课小结。一节课用 2—3 次即可，过多会显得空。

## `stats` 一组数字

```python
{
    "t": "stats",
    "chapter": "序章  ·  一组数字",
    "title": "四个数字，看见青春的分量",
    "sub": "数字是示例，问题是真的",
    "numbers": [
        ("1", "个选择", "把个人理想，放进时代需要。"),
        ("365", "天", "把一件小事，坚持一整年。"),
        ("100", "次", "从失败里站起来，再试一次。"),
        ("N", "种可能", "青春不被定义，但要有方向。"),
    ],
    "note": "示例数据，仅用于版式演示。",  # 可选
    "script": "……",
}
```

- `numbers` 必须 **2—5 组**；
- 每组是 `(数字, 单位/标签, 一句解释)`；
- 数字建议 ≤ 5 个字符，否则会挤压标签。

## `toc` / `toc6` / `toc8` 目录

```python
{
    "t": "toc6",
    "title": "六个问题，一条主线",
    "sub": "CONTENTS  /  从回望来路，到走向远方",
    "items": [
        ("回望来路", "从历史里，找到自己的坐标。"),
        # …共 6 组
    ],
    "script": "……",
}
```

- `toc`：3—8 组，自动排成 2 列或 3 列；
- `toc6`：必须 **正好 6 组**；
- `toc8`：必须 **正好 8 组**；
- 每组是 `(标题, 一句说明)`，标题建议 4—6 字。

## `chapter` 章节页

```python
{
    "t": "chapter",
    "num": "01",
    "cn": "一",
    "title": "回望来路",
    "quote": "知道自己从哪里来，才知道要往哪里去。",
    "img": "examples/assets/mountain_dawn.jpg",  # 可选
    "caption": "示意图 · 脚本生成",              # 可选
    "script": "……",
}
```

- 没有 `img` 时使用内置深红背景，完全可用；
- 有 `img` 时全屏裁切并压深红色遮罩，保证白字可读；
- `caption` 只在有图时显示，写清“示意图”或图片来源。

## `content` 卡片内容页

```python
{
    "t": "content",
    "chapter": "第一章  ·  回望来路",
    "title": "三个坐标，读懂来路",
    "sub": "时间、人民、行动",
    "cards": [
        ("时间坐标", "从历史的长镜头里，看清一代人有一代人的接力。"),
        ("人民坐标", "一切奋斗的落脚点，都是人民的真实需要。"),
        ("行动坐标", "再远的理想，也要从脚下第一步开始。"),
    ],
    "lead": "可选的一句导语",  # 可选
    "note": "示例内容，可替换。",  # 可选
    "script": "……",
}
```

- `cards` 必须 **2—4 组**；
- 每组是 `(小标题, 正文)`；
- 正文建议 ≤ 60 字，超过请拆页；
- 3 张卡片最稳，4 张会自动变窄。

## `timeline` 时间轴

```python
{
    "t": "timeline",
    "chapter": "第一章  ·  时间线",
    "title": "一条时间线，看见接力",
    "sub": "从站起来、富起来到强起来",
    "events": [
        ("1921", "开天辟地", "一个政党，从几十个人出发。"),
        ("1949", "站起来", "中国人民从此站起来了。"),
        ("1978", "富起来", "改革开放，改变中国。"),
        ("2012", "强起来", "新时代，新的历史方位。"),
        ("今天", "接力", "把青春写在祖国大地上。"),
    ],
    "note": "示例时间线，仅用于版式演示。",  # 可选
    "script": "……",
}
```

- `events` 必须 **3—6 组**；
- 每组是 `(年份/节点, 标题, 一句说明)`；
- 5 组最稳；6 组时说明文字要更短（≤ 24 字）；
- 第一个和最后一个节点会自动留边，但仍建议节点标题 ≤ 6 字。

## `person` 人物页

```python
{
    "t": "person",
    "chapter": "第二章  ·  人物",
    "title": "【人物姓名】：把一件事做到极致",
    "sub": "【身份 / 年份】",
    "name": "【人物姓名】",
    "dates": "【生卒年 / 时代】",
    "img": None,                 # 可选；不填则尝试 portraits 映射
    "deeds": [
        ("选择", "【他/她为什么出发】"),
        ("坚持", "【最难的时候做了什么】"),
        ("回响", "【今天留下了什么】"),
    ],
    "quote": "【一句可核对的原话】",
    "photo_note": "人物照片占位",  # 可选
    "script": "……",
}
```

- `deeds` 必须 **正好 3 组**；
- 没有照片时显示金色剪影占位，不会报错；
- 姓名以 `【` 开头时，占位提示会自动变成“请替换为人物照片”；
- **不要**用 AI 生成的人像冒充真实历史人物；
- 肖像版权要求见 [ASSETS.md](ASSETS.md)。

### 自动匹配肖像

在 `CFG` 里配置映射，`person` 页的 `img` 留空即可：

```python
CFG = {
    "portraits": {
        "示例人物": "example.jpg",
    },
    "portrait_dir": "my_assets/portraits",
    ...
}
```

`portrait_dir` 默认是 `red_gold_deck/assets/portraits/`（已被 `.gitignore` 忽略）。

## `two_col` 左右对照

```python
{
    "t": "two_col",
    "chapter": "第四章  ·  表达",
    "title": "两种语言，一种心意",
    "sub": "换的是说法，不换的是把事情办成的心",
    "left_title": "文件里的语言",
    "left_items": [
        ("概念", "先解释定义，再谈背景。"),
        ("流程", "一条一条列清楚，避免遗漏。"),
        ("要求", "用“应当”“必须”，边界明确。"),
    ],
    "right_title": "群众听得懂的话",
    "right_items": [
        ("例子", "先讲一件事，再讲道理。"),
        ("路径", "告诉对方下一步去哪里、找谁。"),
        ("结果", "什么时候办成，给一个准话。"),
    ],
    "note": "好的表达，不是降低标准，而是减少误解。",  # 可选
    "script": "……",
}
```

- 左右各 **2—4 组**；
- 建议左右数量一致，视觉更稳；
- 适合“过去/现在”“问题/办法”“文件语言/群众语言”等对照。

## `fullpic` 整版图片页

```python
{
    "t": "fullpic",
    "chapter": "第一章  ·  现场",
    "title": "把论文写在大地上",
    "sub": "从书桌走向田野，从概念走向问题",
    "img": "examples/assets/field_gold.jpg",
    "points": [
        ("脚下有泥", "到现场去，才知道问题长什么样。"),
        ("眼中有光", "把个人兴趣，接到时代需要上。"),
        ("心中有民", "做出来的东西，要有人真正用得上。"),
    ],
    "caption": "示意图 · 脚本生成",  # 可选
    "script": "……",
}
```

- 图片全屏裁切，上覆 62% 深红遮罩，白字始终可读；
- `points` 建议 **2—4 组**，每组正文 ≤ 30 字；
- 主体（人脸、建筑、地标）尽量放在画面中间，避免被上下裁掉；
- 没有图片时退化为深红章节页，仍然可用。

## `map_page` 左文右图

```python
{
    "t": "map_page",
    "chapter": "第三章  ·  全局",
    "title": "在一张图上，看见全局",
    "sub": "从点到线，再到面",
    "img": "examples/assets/bridge.jpg",
    "points": [
        ("一个点", "先找到一个具体的问题，别贪多。"),
        ("一条线", "把相关的人、事、资源连起来。"),
        ("一个面", "从个案里，看见结构性的答案。"),
    ],
    "caption": "示意图 · 脚本生成",  # 可选
    "footnote": "示意图，仅用于版式演示。",  # 可选
    "script": "……",
}
```

- 右侧是 **3.54 × 4.30 英寸竖版**画框，图片会居中裁切；
- 适合地图、竖版海报、人物立像、界面截图；
- `points` 建议 3 组，正文 ≤ 45 字；
- 竖版图片效果最好；横图会裁掉左右两侧。

## `sources` 来源与版权

```python
{
    "t": "sources",
    "title": "图片与资料说明",       # 可选
    "sub": "示例页面，可替换为你的真实来源",  # 可选
    "items": [
        ("文字资料", "……"),
        ("图片来源", "……"),
        ("字体说明", "……"),
        ("授权方式", "代码 MIT；图片 CC0。"),
        ("隐私说明", "不含真实姓名、单位、学号、联系方式与个人照片。"),
    ],
    "script": "……",
}
```

- `items` 是 `(标题, 说明)` 列表，建议 4—6 组；
- 如果在 `CFG` 里设置了 `image_credit`，会自动追加一条“图片版权”；
- 公开分享前，这一页是隐私与版权的最后一道检查。

## 组合建议

| 场景 | 推荐页面 |
|---|---|
| 30 页以内 | 封面 + 序章 3 页 + 5 章 × 4 页 + 结语/致谢/来源 |
| 40—50 页 | 封面 + 序章 4 页 + 6 章 × 5—6 页 + 结语/致谢/来源 |
| 人物主线 | 每章 `person` + `quote` + `fullpic` |
| 实践汇报 | `content` + `timeline` + `map_page` + `listpage` |
| 纪念主题 | `timeline` + `fullpic` + `quote` + `sources` |

每章至少换一次版式；连续三页 `content` 会明显单调。
