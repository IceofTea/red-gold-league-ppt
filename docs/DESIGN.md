# 视觉规范与质检清单

## 画布与网格

- 画布：16:9，13.333 × 7.5 英寸（`SW`, `SH`）；
- 左右安全边距：0.85 英寸；
- 页眉基线：0.40 英寸；标题基线：0.82 英寸；
- 正文起始：2.1—2.6 英寸；
- 页脚：6.42 英寸，页码右下角。

超过安全边距的文字，渲染后大概率会被投影仪裁掉。

## 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| `RED` | `#9E1B1B` | 主色、标题、卡片顶条 |
| `DEEP` | `#6E0C0C` | 深红底、图片遮罩 |
| `BRIGHT` | `#C0271E` | 强调、少量点缀 |
| `GOLD` | `#C8A45D` | 线条、编号、页眉星标 |
| `LGOLD` | `#E8D3A3` | 深底上的副标题 |
| `CREAM` | `#F7F1E5` | 浅底区块 |
| `INK` | `#2B241E` | 正文 |
| `GRAY` | `#6F655B` | 注释、说明 |
| `PALE` | `#FBF6EC` | 卡片底 |

规则：

- 一页最多一个主色块，不要红金对半开；
- 金色只做线条、编号和小字，不做大面积填充；
- 深红底上的正文用 `LGOLD` 或白色，不用 `GRAY`。

## 字号

| 元素 | 字号 |
|---|---|
| 封面主标题 | 48—60 pt |
| 章节页大数字 | 118 pt |
| 章节页标题 | 28—48 pt（按字数自动缩） |
| 内容页标题 | 36—38 pt |
| 卡片小标题 | 15—16.5 pt |
| 卡片正文 | 11 pt |
| 时间轴说明 | 9.2 pt |
| 页脚 | 9—10 pt |

不要为了塞内容把正文降到 8 pt 以下。内容多就拆页。

## 版式节奏

推荐每章 4—5 页，版式轮换：

```text
chapter → content → timeline/person → fullpic/map_page → quote
```

避免：

- 连续三页 `content`；
- 连续两页 `fullpic`（遮罩相同，会显得重复）；
- 每章都用同一张场景图。

## 图片处理

- 一律用 `add_pic_cover()` 裁切填充，保持比例；
- 全图页上覆 72% 深红遮罩，保证白字可读；
- 章节页右侧画框 3.98 × 5.15 英寸，主体放中间；
- `map_page` 右侧是 3.54 × 4.30 英寸竖版画框，横图会被裁掉两侧；
- 人像不要拉伸，不要用 AI 生成的人像冒充真实人物；
- 图片来源写在 `sources` 页，示意图标注“示意图”。

## 渲染检查清单

生成后逐页看，按下面顺序：

### 封面

- [ ] 主标题没有换行或压到副标题；
- [ ] `lead` 两行没有超出左边距；
- [ ] 右下角大数字没有和页脚重叠。

### 目录

- [ ] 6/8 张卡片在画布内；
- [ ] 卡片标题没有换行；
- [ ] 卡片说明没有溢出卡片底部；
- [ ] 最后一张卡片右边距 ≥ 0.85 英寸。

### 章节页

- [ ] 大数字没有压到章节标题；
- [ ] 标题在 1 行内，或按预期换行；
- [ ] 引文不超过 3 行；
- [ ] 右侧图片没有裁掉主体；
- [ ] 图片说明没有压到页脚。

### 内容页

- [ ] 2—4 张卡片等宽、等距；
- [ ] 第 4 张卡片没有超出右边界；
- [ ] 卡片正文没有溢出卡片底部；
- [ ] `note` 没有和页脚重叠。

### 时间轴

- [ ] 第一个节点文字没有超出左边界；
- [ ] 最后一个节点文字没有超出右边界；
- [ ] 年份、标题、说明三层没有互相重叠；
- [ ] 6 个节点时说明文字仍然可读。

### 人物页

- [ ] 肖像没有变形；
- [ ] 占位提示清楚，不会被误认为真实照片；
- [ ] 三件事的编号、标题、说明对齐；
- [ ] 原话没有压到页脚。

### 全图页 / 地图页

- [ ] 白字在图片最亮处仍然可读；
- [ ] 主体没有被上下裁切；
- [ ] `caption` 与图片边缘对齐；
- [ ] `points` 四组时没有挤在一起。

### 结语 / 致谢 / 来源

- [ ] 标语在安全区内；
- [ ] 来源页每一项都在自己的列内；
- [ ] 6 项时字号没有小到不可读；
- [ ] 隐私说明与图片版权都在。

## 常见返工原因

| 现象 | 原因 | 处理 |
|---|---|---|
| 标题压字 | 标题超过 18 字，或 `y` 被手改 | 缩短标题，交给 `title_size()` |
| 卡片溢出 | 正文超过 60 字 | 拆页或删字，不要缩字号 |
| 时间轴裁切 | 6 个节点 + 长标题 | 节点标题压到 4—6 字 |
| 图片变形 | 直接改宽高 | 用 `add_pic_cover()` |
| 白字看不清 | 图片太亮、遮罩太浅 | 提高遮罩到 72%，或换图 |
| 页数不符 | 增删页面没改 `expect_pages` | 同步修改配置 |
| 字体回退 | 本机没装字体 | 设置 `RED_GOLD_*_FONT` |
