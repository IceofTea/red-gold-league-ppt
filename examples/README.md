# 示例课件

这个目录是一份完整的、可直接打开的示例，也是生成器的回归样本。

| 文件 | 说明 |
|---|---|
| `示例_把青春写在祖国大地上_31页.pptx` | 31 页示例团课，12 张配图 |
| `示例_讲稿_把青春写在祖国大地上_31页.docx` | 与 PPT 逐页对应的 Word 讲稿 |
| `demo.py` | 生成上面两个文件的配置 |
| `assets/` | 12 张 CC0 示意图（脚本生成） |

## 重新生成

```bash
python demo.py
```

输出在仓库根目录的 `out/demo/`，不会覆盖本目录里的成品。

## 内容与隐私

- 主题是通用的“把青春写在祖国大地上”，不涉及具体单位、支部、真实人物；
- 人物页使用 `【人物姓名】` 占位，演示“没有照片时如何安全排版”；
- 所有姓名、单位、数字均为占位或示例；
- 配图不含真实人物、地点、标志或文字；
- 图片由 `scripts/make_demo_assets.py` 生成，CC0 1.0。

## 替换成你的主题

1. 复制 `demo.py` 为 `my_deck.py`；
2. 修改顶部 `CFG`（footer / header / topic / expect_pages）；
3. 按章节替换 `PAGES` 里的标题、正文、讲稿；
4. 把 `assets/` 里的示意图换成自有或已授权图片；
5. `red-gold-deck build my_deck.py`；
6. 渲染成图逐页检查，重点看标题、卡片、时间轴和图片裁切。

字段说明见 [`../docs/PAGES.md`](../docs/PAGES.md)。
